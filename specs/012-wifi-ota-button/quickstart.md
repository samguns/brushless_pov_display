# Quickstart

1. Build with `cmake --build build`.
2. Open Settings: verify **Update Firmware (USB)** and **Update Firmware (WIFI)** actions.
3. Verify USB follows its existing confirmation/BOOTSEL route.
4. Open Update Firmware (WIFI): verify package guidance, restart warning, styled progress bar/percentage, status, and USB recovery link.
5. Upload a compatible package and verify reconnect/identity; submit an invalid package and verify USB remains available.
